# mf-btc-cent-forecast-01

Entry for the make.fun forecast bounty `btc-cent-forecast-01`. `main.py` (Python 3, stdlib only)
reads each case in the input directory and writes the 4-hour-ahead BTC price
forecast to the output directory. Damped linear-trend model. Deterministic,
offline, no clock.
